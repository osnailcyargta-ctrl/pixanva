Tentang Pixanva

Pixanva adalah image generator berbasis transformer decoder-only yang dibangun from scratch — tanpa PyTorch, TensorFlow, atau pre-trained model. Arsitektur, attention, RoPE 2D, backprop manual, dan optimizer ditulis sendiri (cek folder training/ di repo).

Cara kerja: model autoregressive memprediksi warna palet (96 warna) sel demi sel dari kiri-atas ke kanan-bawah — lo bisa lihat langsung setiap sel diketok warna saat model "ngitung". Tag pilihan lo (pemandangan, warna, suasana, ornamen) di-encode jadi prefix tokens yang dikondisikan lewat attention, plus classifier-free guidance (12% kondisi dibuang saat training) supaya pengaruh tag bisa diperkuat saat sampling — makanya hasilnya nyambung sama pilihan lo.

Semua inferensi jalan 100% di browser lo — bobot model (fp16) di-fetch lalu dihitung pakai JavaScript murni. Gak ada server, gak ada API.

Resolusi: 32px = grid 16×16, 64px = grid 32×32, 96px = grid 48×48 — semua dilukis native sel-per-sel. 128px = grid 48×48 yang dihaluskan (bilinear antar sel + kuantisasi ulang ke palet + dither bayer) — tahap "menambah detail" ini bisa lo lihat jalan per-band. Pixanva Light cuma dilatih grid 16/32, jadi 96/128px-nya pakai sel lebih besar.

Model & versi: Light & Dark pakai penomoran desimal — naik 0.2 = update menengah (latihan lebih lama), naik 0.3 = update besar (parameter beneran ditambah: Dark 1.5 naik dari 2.7M jadi 4.9M parameter, 6 → 8 lapis attention). Heavy pakai skema QWERTY: dua huruf berurutan sesuai layout keyboard (q→w→e→r→t→y→u→i→o→p→a→s→d→f→g→h→j→k→l→z→x→c→v→b→n→m) — setiap naik satu huruf dihitung +0.2 versi: QQ, lalu QW, QE … sampai QM, lanjut WQ, WW, WE … dan seterusnya. Tiga model utama (versi terbaru tiap keluarga) nanggung di layar depan; semua versi lama tetap bisa dipilih lewat More models — bisa di-sort terbaru / terpintar dan dibalik urutannya.

Fitur: variasi ×4 (satu prompt dilukis jadi 4 kandidat beda seed, tinggal pilih), prompt dadu 🎲 buat yang males mikir, layar loading yang nge-blur seluruh gambar sekali + reveal per baris real-time pakai kuas virtual, dan tombol asisten ✦ melayang yang bisa di-drag — chat sama dia buat minta ide prompt: 3 pilihan set, bisa minta ulang, ada negative prompt.

Tema: 8 tema tampilan bisa diganti di Pengaturan — Classic Dark / Light / Metalic, Paper Doodle, CapCut Typshit, Neon, Senja, dan Hacker Terminal. Mode CapCut sekarang jadi salah satu tema (lengkap dengan navigasi bawah ala editor video).

Asisten prompt sekarang diotaki LLM transformer beneran dilatih dari nol (assistant.bin, ±6.9M parameter) yang jalan 100% di browser — kalau bobotnya belum ke-load, dia otomatis turun ke otak rule-based biar tetap bisa diajak ngobrol.

Posisi token: kondisi di (i, 0), sel gambar di (baris, kolom+16) lewat RoPE 2D faktoris — satu model bisa gambar berbagai resolusi grid.
